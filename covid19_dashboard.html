Key Project Insights
🇧🇷
Brazil Dominates Case Count
Brazil (BRA) accounts for 836,244 new cases — nearly 57% of all cases in the dataset, with a peak of 63,523 in a single day (June 20, 2020).
🌎
South America Hit Hardest
South America records 857,461 new cases and 31,227 deaths — the highest of all continents, driven primarily by Brazil's outbreak.
📈
Cases–Deaths Strongly Correlated
The Pearson correlation between total_cases and total_deaths is r = 0.943, indicating that as case counts rise, deaths rise proportionally across countries.
💉
Vaccination Surge in 2022
Total vaccinations spiked to 10.26 million in January 2022, reflecting mass vaccination campaigns. Vaccination began near zero through most of 2020.
🏙️
Population Drives Case Load
Population and total_cases are correlated at r = 0.933. Larger population countries like India (IND: 288K cases) and Brazil show the highest burdens.
💰
GDP vs COVID – Weak Link
Despite BRN leading in GDP/capita at \$71,809, GDP shows a weak negative correlation (r = -0.07) with total_cases, suggesting wealth alone doesn't prevent spread.
🧹
Data Quality: Well-Handled
Original dataset had 10 missing values (~1%) in demographic columns (GDP, population, life expectancy). All filled using per-country median, producing a clean 999-row dataset.
☠️
Deadliest Single Day
The maximum single-day death toll in the dataset is 1,510 deaths, with Brazil responsible for the highest cumulative death count of 30,365.
🏥
Preprocessing Pipeline
The project implements a robust pipeline: column selection (21 features), median-fill by country, 80/20 train-test split, Z-score normalization, and Gaussian noise augmentation for model readiness.

Preprocessing Pipeline
Steps applied from raw data to model-ready arrays
1
Load Excel Dataset
pd.read_excel("DAE project.xlsx") → 999 rows × 41 cols
2
Feature Selection
Select 21 key columns → df2 (999 × 21)
3
Handle Missing Values
Fill 9 columns using country-level median (groupby)
4
Train/Test Split (80/20)
799 train rows, 200 test rows (random seed=42)
5
Z-Score Normalization
(X − train_mean) / train_std on 17 numeric features
6
Gaussian Noise Augmentation
noise_factor=0.1 → X_train_noisy, X_test_noisy
